名词解释

这些术语是什么意思？

这份报告涉及很多专业术语。如果你不熟悉这个领域，先看这里。

流程挖掘 Process Mining

从企业 IT 系统（ERP、CRM）的日志数据中，自动"挖掘"出业务流程实际是怎么运行的——哪个步骤最慢、哪里有瓶颈、多少流程偏离了标准。

举例：从 SAP 日志发现采购审批平均比规定流程多了 3 个步骤

RPA Robotic Process Automation

"机器人流程自动化"——用软件模拟人的鼠标和键盘操作，自动执行重复性任务。不是物理机器人，是软件机器人。

举例：自动从邮件提取发票信息并录入财务系统

超自动化 Hyperautomation

Gartner 提出的概念——把 RPA、AI、流程挖掘、低代码等多种技术组合起来，实现端到端的业务流程自动化。是比 RPA 更大的概念。

流程智能 Process Intelligence

2026 年 Gartner 将"流程挖掘"升级为的新品类名——不再只是挖掘/分析，还包含建模、模拟、执行、监控、治理。覆盖流程的全生命周期。

Agent 工作流 Agent Workflow

由 AI Agent（而不是固定脚本）执行的工作流。每个节点可以是 LLM 调用、API 请求或自主 Agent 推理。比传统 RPA 更灵活，比纯 Agent Loop 更可控。

举例：上传一份 SOP 文档 → 自动生成多步骤审批工作流 → 执行

声明式 YAML Declarative YAML

用 YAML 格式声明"做什么"（节点、连接、条件），而不是"怎么做"（代码）。类似 GitHub Actions 的 workflow YAML。好处是可读、可版本化、可让 AI 生成。

PS 倍数 Price-to-Sales

估值 ÷ 年收入（ARR）。用来衡量公司值多少钱的常用指标。比如估值 100 亿、收入 10 亿，PS 就是 10x。不同赛道的 PS 差异很大——传统 RPA 约 4x，AI Agent 公司可达 79x。

MCP Model Context Protocol

Anthropic 提出的标准协议，让 AI Agent 可以连接外部系统获取上下文。Celonis 和 SAP 都已推出 MCP Server，让 Agent 能读取企业流程数据。

核心论证

为什么这个产品贴合流程智能赛道

产品定位"从自然语言和文档自动生成 Agent 工作流"——这恰好命中了流程智能市场的核心痛点和最新趋势。

三个"刚好命中"

① 刚好命中"SOP 文档→自动化"的鸿沟

企业有大量 SOP（标准操作流程）文档，但把这些文档变成可执行自动化流程需要 20-80 人时/文档类型（来源：arXiv:2607.26075 IDP AutoOpt）。产品的"文档→工作流"能力直接跨越这道鸿沟。

② 刚好命中行业 AI 转型趋势

Celonis 正在发布 MCP Server 和 AI Agent 上下文层；SAP Signavio 推出 Text-to-Process（自然语言→流程模型）和 Agent Mining。行业头部公司都在往"AI + 流程"方向走，但它们的底层是重型企业平台。我们用轻量级 YAML + LangGraph 做同样的事。

③ 刚好命中 Progressive Crystallization 的 Stage 3

学术论文（arXiv:2607.07052）证明：Agent 自主探索验证完毕后，会"结晶"为确定性 Workflow。产品输出的 workflow.yaml 就是这个结晶产物——成本降 70%+，可靠性大幅提升。

和德国双雄的差异化定位

维度 Celonis / SAP Signavio 我们的方案
流程发现方式 从 ERP/CRM 事件日志挖掘 从自然语言 + 文档生成
输出物 分析报告 + 可视化 可执行的 Agent 工作流 YAML
部署周期 数月（连接 ERP、配置管道） 数分钟（上传文档即可）
客户画像 Fortune 500 大企业 中型企业 + 大企业部门级
开放性 封闭平台 MIT 开源 YAML 标准
定价 $10 万-$100 万+/年 按使用量 / SaaS 订阅

关键洞察：Celonis 和 SAP 的客户是 Fortune 500——这些公司有完整的 SAP/Oracle 系统，日志数据完备。但全球有数百万家中型企业没有完整 ERP，只有 SOP 文档。这是被德国双雄忽略的市场。

市场规模

三个口径看市场规模：RPA、超自动化、流程挖掘。每个口径包含和被包含的关系不同。

中国市场规模推导

推导方法见下方

中国没有权威的独立流程挖掘市场数据。以下用三种方法交叉推导：

方法 A：全球占比法
全球流程挖掘市场 $15-25 亿 × 中国 IT 支出全球占比 ~15% = $2.25-3.75 亿
方法 B：头部公司倒推法
来也 ARR ~$1-2 亿 + 弘玑 ~$0.5-1 亿 + 达观 ~$0.3-0.5 亿 + 其他 5+ 家 ~$1 亿 = $2-4.5 亿
方法 C：市值比例法
美国上市科技公司总市值 ~$40 万亿 / 中国 A 股 + 港股科技 ~$6 万亿 = 美国 : 中国 ≈ 6.7 : 1
全球流程挖掘 ~$20 亿 / 6.7 = ~$3 亿

三种方法交叉验证 → 中国流程挖掘市场约 $3-5 亿（约 20-35 亿人民币），增速与全球一致或更快（30-40% CAGR）。
