10AIAI · 开源工具
AI · 开源工具

吴恩达与前 Alexa 负责人开源本地 AI 代理 OpenWorker

吴恩达与 Rohit Prasad（前亚马逊 Alexa 负责人）开源的本地 AI 代理项目 OpenWorker 在 GitHub 走红——定位是"交付成果的本地 AI 同事"，而非聊天机器人。

项目为四层架构：Tauri+React 桌面端、Python+FastAPI 本地服务器、25 多个工具连接器、以及支持 30 多个模型（含 Ollama 本地模型）的路由层，采用 aisuite 库做模型路由，跨 Mac/Windows 平台、本地优先。

最受关注的是权限设计：四级风险等级（read / write_local / exec / external）× 五种运行模式（discuss / plan / interactive / auto / custom），实现细粒度控制，且"无人值守模式不会提升 Agent 的自主权限上限"。

对开发者而言，它代表 AI 代理从云端 API 走向本地桌面原生应用的一个方向：数据留在本机、模型中立、可自由定制，也为本地 Agent 的安全边界提供了一套可复用的参考范式。Rohit Prasad 的加入让这个项目带有消费级产品经验的色彩。

关键事实

四层架构、25+ 工具、30+ 模型支持；四级风险等级 × 五种权限模式
