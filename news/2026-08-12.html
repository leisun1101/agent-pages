澳大利亚为外卖骑手设立「世界领先」最低工资与保险规则

澳大利亚公平工作委员会发布新规：外卖与生鲜配送骑手最低时薪至少 31.30 澳元（约 22 美元），高于全国最低工资；平台须为骑手提供人身意外险。新规 8 月 17 日生效，覆盖约 25 万工人。

新规由工会与 DoorDash、Uber Eats 联合申请促成：骑手按「接单至送达」的 engaged 时间计薪，最低时薪 31.30 澳元，高于全国最低工资 26.44 澳元；平台须提供「合理最低保障」的人身意外险，工人自担车辆第三方保险。工会称这是「澳洲零工经济的里程碑时刻」，「从周一起他们将领受一套绝对世界领先的标准」。

DoorDash · 工程

DoorDash 发布 Flux：把工程工作委托给云端 Agent

DoorDash 工程博客介绍自建的云端编码 Agent 平台 Flux：以 Firecracker 微虚拟机沙箱、自研 MCP 网关和 YAML playbook 为原语，把工程任务委托给云端智能体执行；2026 年单月自动化 13 万项工程任务。

Flux 四大原语：Firecracker 微虚拟机沙箱（硬件级隔离）、自研 MCP 网关 Agent Gateway（按 playbook 声明的最小权限授权、全程审计）、单个 YAML 文件定义的 playbook（可混合 agent 步骤与确定性步骤）、多调用入口（Slack/GitHub/cron/CLI/skill）。沙箱端到端配置 95 分位小于 5 秒。2026 年单月自动化 13 万项工程任务，每周超 2.5 万次自动代码评审、300+ playbook、1 万+ 次调用，可无人值守并行全天运行。

动机是笔记本跑 agent 的三重限制：资源与可用性（关机断网即停）、安全控制（本地凭证暴露面大）、可观测性差；且不想把敏感代码交给第三方托管 agent，故自建并掌控编排、沙箱、权限等原语。团队奉行「原语而非工作流」，先以高频可衡量的代码评审切入建立信任，再扩展至 CI 分流、on-call 等，公开 Slack 线程提升可见性。

关键事实

单月自动化 13 万项工程任务；每周 2.5 万+ 次自动代码评审；沙箱配置 p95 < 5 秒

开源 · 安全

Mozilla 撤销 Firefox 签名密钥：未加密副本误入 GitHub

Mozilla 披露有人将未加密的 GPG 私有签名子密钥副本误提交到私有 GitHub 仓库，随即撤销并更换该密钥；审计未发现被未授权访问的证据，但 Fedora 42 及更早、RHEL、openSUSE 等用户需手动换钥。

该子密钥用于签名 Firefox/Thunderbird 的 Linux tarballs、RPM 包和校验和文件。Mozilla 周一（8/11）披露事件，撤销子密钥并更换、新增防护措施，但未说明密钥如何入库及停留时长；审计结论「未发现密钥在仓库期间被未授权方访问的证据」。Fedora 43+ 可自动更新密钥（需批准导入），Fedora 42 及更早、RHEL、Rocky、AlmaLinux、openSUSE、SUSE 用户须手动移除旧密钥、导入新密钥；Thunderbird 无官方 RPM 不受影响。

签名密钥是 Firefox/Thunderbird Linux 发布流程的信任根基——让用户和包管理器验证软件确来自 Mozilla、未被篡改。事件暴露了供应链密钥管理的薄弱环节（私钥明文入库），对用户而言多数人无需操作，但手动校验 GPG 签名的用户及部分发行版用户需手动换钥，旧版签名校验将被拒绝。
